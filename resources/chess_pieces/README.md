# Chess Pieces SVG Collection

This directory contains SVG chess pieces for use in the Chess Game with Stockfish.

## Pieces

### Black Pieces
- `black_rook.svg` - Rook
- `black_knight.svg` - Knight  
- `black_bishop.svg` - Bishop
- `black_queen.svg` - Queen
- `black_king.svg` - King
- `black_pawn.svg` - Pawn

### White Pieces
- `white_rook.svg` - Rook
- `white_knight.svg` - Knight
- `white_bishop.svg` - Bishop
- `white_queen.svg` - Queen
- `white_king.svg` - King
- `white_pawn.svg` - Pawn

## Usage

The SVG files use standard chess piece designs with:
- ViewBox: `0 0 100 100`
- Scalable vector graphics
- Black pieces: Solid black fill
- White pieces: White fill with black stroke

## Integration

To use these SVG pieces in the chess game, you can:
1. Load SVG files into the GUI
2. Use them as icons for buttons
3. Convert to bitmap for display

These SVG files are ready to be integrated into any GUI application that supports SVG rendering.
