========================================

   v1: GuiControl,, ControlName, value
   v2: control.Text := value

SetTimer with labels → SetTimer with functions

Menu, Tray → A_TrayMenu
   v1: Menu, Tray, Add, Item, Label
   v2: A_TrayMenu.Add("Item", (*) => Function())

   v1: LabelName:
